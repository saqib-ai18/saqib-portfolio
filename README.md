# Mohammed Saqib — Portfolio

A responsive, dark cyber-inspired personal portfolio built with React and Vite.

## Run it on Windows

1. Extract `saqib-portfolio.zip`.
2. Open the extracted `saqib-portfolio` folder in VS Code.
3. Open Terminal → New Terminal.
4. Run:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local address printed in the terminal (usually `http://localhost:5173`).

## Personalize before publishing

Open `src/App.jsx` and update these placeholders:
- `YOUR_EMAIL@example.com` → your professional email
- `https://www.linkedin.com/` → your LinkedIn profile URL
- `https://github.com/` → your GitHub profile URL
- Add GitHub/demo links for each project when available.
- Check all project descriptions and technologies match what you personally did.

You can edit colours and layout in `src/index.css`.

## Build for deployment

```bash
npm run build
```

The production-ready website files will be generated in the `dist` folder. You can deploy this Vite project free on Vercel or Netlify.
